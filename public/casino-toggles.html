How to drop these into the app

Theme is driven by toggling the .dark class on <html> — the exact mechanism this Next app already uses (app/globals.css: @custom-variant dark (&:is(.dark *))). So "lights on" maps to light mode and the switch is portable as-is.

To reuse one toggle in a React component: copy a single <button class="toggle …"> block, move its scoped <style> rules into your CSS, and call the same flip() logic from the button's onClick (or wire it to your theme store / next-themes). The animation is pure CSS keyframes triggered by adding the throwing / pulling class, so no animation library is needed.

Carried over from the pull-chain lamp: pre-paint theme (no flash), localStorage('pc-theme'), OS-default until an explicit choice, full prefers-reduced-motion fallback, and real <button>s with aria-pressed + visually-hidden labels.
